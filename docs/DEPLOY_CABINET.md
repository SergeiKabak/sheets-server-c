# Инструкция: «Кто в кабинете с Бинкевич в этот день» (Вариант А)

## Что сделано

1. Эндпоинт `GET /api/cabinet?month=...&cabinet=...&day=...`
   (`src/app/month_api.c` — сценарий, `src/web/api_schedule.c` — HTTP-обработчик):
   возвращает JSON со списком коллег (кроме сотрудника из `SEARCH_NAME`),
   которые в указанный день работают в указанном кабинете.
2. Фронтенд — в модульных скриптах Mini App: `web/js/calendar.js` рисует
   кликабельные ячейки кабинетов и открывает диалог коллег, `web/js/api.js`
   дергает `/api/cabinet` (передаёт ещё и смену — фильтр по пересечению).

Изменения уже влиты в ветку `main` и запушены на GitHub.

---

## Шаг 1. Убедиться, что сервер на Render обновлён

Эндпоинт `/api/cabinet` живёт в этом репозитории. Чтобы он заработал на проде,
проверьте, что на Render задеплоен актуальный коммит:

1. Откройте `https://sheets-server-c.onrender.com/version` — в ответе
   `"commit"` должен совпадать с последним коммитом ветки `main` на GitHub.
2. Если не совпадает — на Render выполните редеплой сервиса `sheets-server-c`
   (Render автоматически соберёт Docker-образ и перезапустит контейнер).
3. Проверьте эндпоинт в браузере:
   ```
   https://sheets-server-c.onrender.com/api/cabinet?month=Октябрь%202026&cabinet=К2.1&day=5
   ```
   Ожидаемый ответ:
   ```json
   {"cabinet":"К2.1","month":"Октябрь 2026","day":5,"shift":"","colleagues":[{"name":"...","shift":"..."}]}
   ```

---

## Шаг 2. Фронтенд

Функциональность уже встроена в Mini App (`web/js/`) — отдельный скрипт
(oneline-патч поверх монолитного кода) не нужен и удалён.

- `web/js/calendar.js` — кликабельные ячейки кабинетов + диалог коллег;
- `web/js/api.js` → `A.api.colleagues(month, day, cabinet, shift)` — запрос
  на `/api/cabinet`.

Если хотите показать коллег где-то ещё — вызывайте тот же эндпоинт
`GET /api/cabinet?month=...&cabinet=...&day=...&shift=...` (для кириллицы —
через `encodeURIComponent`).

---

## Шаг 3. Проверка

1. Откройте Telegram Web App.
2. Выберите месяц (например, Октябрь 2026).
3. Нажмите на любую ячейку с кабинетом в строке нужного дня (например, `К2.1`).
4. Должно появиться окно со списком людей, которые в этот же день работают
   в этом же кабинете (с учётом пересечения смен).

---

## Примечания

- Сервер исключает своего сотрудника из списка коллег (`SEARCH_NAME`).
- Пустая ячейка кабинета не кликабельна.
- Пустой список `colleagues` — «никто другой не работает в этом кабинете в этот день».
- Для кириллицы в названиях месяцев и имен кабинетов используется URL-кодирование
  (`encodeURIComponent` на клиенте, `url_query_param`/`url_decode_into` из
  `src/core/url_codec.c` на сервере).
