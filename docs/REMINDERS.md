# Напоминания о смене

Бот умеет прислать сообщение о завтрашней смене. Напоминание ставится
кнопкой, хранится в Supabase и отправляется фоновым циклом сервера.

## Как пользоваться

1. В чате с ботом нажать кнопку **«Напомнить»** (reply-клавиатура) или
   отправить `/remind`.
2. Выбрать время инлайн-кнопкой:
   - **08:00 / 09:00 / 20:00** — завтра в это локальное время;
   - **За час до смены** — за 60 минут до начала завтрашней смены
     (время берётся из графика; если смен две — по более ранней);
   - **Отменить напоминания** — удаляет все неотправленные напоминания чата.

Бот сразу отвечает подтверждением и текстом, что завтра по графику:
смена, время, кабинет (или «смен в графике нет»).

Пример:

```
Ок! Напомню завтра в 09:00.
Завтра, 28.10.2026: смена 7:30-14:40 (кабинет K2.1).
```

## Как это устроено

- `src/domain/reminder.c` — чистая функция `reminder_plan()`: считает момент
  отправки по локальному часовому поясу (`TZ_OFFSET`) и собирает текст из
  кэша графика. Покрыта `tests/test_reminders.c`.
- `src/infra/supabase.c` — `sb_reminder_add/due/mark_sent/cancel`
  (PostgREST, таблица `reminders`).
- `src/app/reminder_service.c` — сохранение и отправка созревших напоминаний.
- `src/app/background.c` — раз в `CACHE_TTL` (60 с) вызывает
  `reminders_flush()`: выбирает `sent = false and remind_at <= now`,
  отправляет через Bot API и помечает `sent = true`.

## Установка

Один раз выполнить SQL из `docs/sql/reminders.sql` в Supabase → SQL Editor.

Пока таблицы нет, бот ответит «Не удалось сохранить напоминание: база
недоступна», остальные функции работают как раньше.

## Ограничения

- Время отправки — с точностью до тика фонового цикла (до ~60 секунд).
- Если процесс сервера не работает, напоминание не уйдёт: на free-тарифе
  Render инстанс засыпает без HTTP-трафика. На платном плане фоновый цикл
  работает постоянно.
- Доставку Bot API подтвердить нельзя: после отправки напоминание помечается
  отправленным, чтобы не зацикливаться при сбое сети.
